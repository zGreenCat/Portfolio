# Imágenes Necesarias para el Portfolio

Para que la animación funcione correctamente, necesitas agregar **4 imágenes PNG** en la carpeta `/public/intro/`

## Ubicación y nombres de archivo:

1. `/public/intro/intro-1.png` - Primera imagen (pose inicial)
2. `/public/intro/intro-2.png` - Segunda imagen (transición)
3. `/public/intro/intro-3.png` - Tercera imagen (transición)
4. `/public/intro/intro-4.png` - Cuarta imagen (pose final)

## Requisitos de las imágenes:

- **Formato:** PNG con fondo transparente
- **Dimensiones sugeridas:** 800x1000px o similar (proporción vertical)
- **Contenido:** Fotos/poses de Vicente Araya que varían ligeramente
- **Estilo:** Las imágenes se irán revelando progresivamente con el scroll, así que considera poses que cuenten una historia visual

## Efecto visual:

- Cada imagen tendrá una **sombra/silueta verde oscura** (#4A5E52) detrás
- Las imágenes aparecerán una tras otra mientras haces scroll
- La transición entre imágenes es suave y sincronizada con el efecto de lectura del texto

## Cómo agregar las imágenes:

1. Crea la carpeta `public/intro/` si no existe
2. Coloca tus 4 imágenes PNG con los nombres exactos mencionados arriba
3. Asegúrate de que los nombres coincidan exactamente (intro-1.png, intro-2.png, etc.)

## Placeholder temporal:

Si aún no tienes las imágenes listas, puedes usar imágenes placeholder temporales o crear archivos PNG simples para probar la animación.
